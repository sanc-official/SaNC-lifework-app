# スプレッドシート連携（GAS）セットアップ

このアプリは標準ではブラウザ内（localStorage）にのみ保存されます。
Google Apps Script (GAS) を介してスプレッドシートに保存すると、
**スマホとPCで同じデータを共有**できます（追加費用なし）。

## 仕組み

```
スマホ/PC のアプリ ──HTTP──> GAS Web App ──> Google スプレッドシート
```

- スプレッドシートに「1日1行」で記録されます
- 保存時にシートへ送信、起動時にシートから取得
- 同じ日付は「更新日時が新しい方」を優先してマージ
- 削除はソフト削除（`deleted` 列が `true`）。行は残るので履歴も追えます

## セットアップ手順

### 1. スプレッドシートを作成

[sheets.new](https://sheets.new) などで新規スプレッドシートを作成します。
名前は任意（例: `SaNC Lifework Log`）。

### 2. スクリプトを貼り付け

1. スプレッドシートのメニュー **拡張機能 > Apps Script** を開く
2. デフォルトの `コード.gs` の中身を全部消す
3. このフォルダの [`Code.gs`](./Code.gs) の内容をコピーして貼り付け
4. 保存（💾）

### 3. ウェブアプリとしてデプロイ

1. 右上 **デプロイ > 新しいデプロイ**
2. 歯車アイコン > **ウェブアプリ** を選択
3. 設定:
   - 説明: 任意
   - **実行ユーザー: 自分**
   - **アクセスできるユーザー: 全員**
4. **デプロイ** を押す
5. 初回は権限の承認を求められるので許可
6. 表示された **ウェブアプリのURL**（末尾が `/exec`）をコピー

> ⚠️ 「アクセスできるユーザー: 全員」にしないと、アプリから読み書きできません。
> URLは推測されにくいランダム文字列なので、URLを知っている人だけがアクセスできます。
> 機微な情報は記録しない前提で運用してください。

### 4. アプリに登録

1. アプリ右上の ⚙️（設定）ボタンを押す
2. URL欄にコピーした `/exec` URL を貼り付け
3. **保存して同期** を押す

「同期済み」と表示されれば成功です。

## コードを更新したとき

`Code.gs` を編集したら、**デプロイ > デプロイを管理 > 編集（鉛筆）> バージョン: 新バージョン > デプロイ**
で再デプロイしてください。URLは変わりません。

## トラブルシュート

- **「同期エラー」になる**
  - URL末尾が `/exec` か確認（`/dev` ではない）
  - デプロイの「アクセスできるユーザー」が「全員」か確認
- **データが片方の端末にしか出ない**
  - 両端末で同じURLを設定しているか確認
  - 同期ボタンを押して手動同期
- **シートに変な列がある**
  - 1行目のヘッダーは `Code.gs` の `FIELDS` と一致している必要があります。
    手で編集せず、空のシートからやり直すのが確実です。
